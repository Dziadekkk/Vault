## PROLOGUE: The Vault v9.0 "Back to Home" Edition

==================================================================================

The Vault's roots go back to the ancient days of modding (I remember "installing"
one of its early versions for the first time by simply copying and pasting files into
the `override` directory).

Since then, a lot has changed within the mod itself, but nothing has changed about my
love for it. I must admit that the split caused by the creation of the *Vauleet* version
hit me hard. I used to install and play the *Vauleet* version, which is free of the
official SHS version's bugs, and kept waiting for a refreshed update of the official release...
and waiting...

Until finally, an idea was born – why not me? Why not try to merge the last official SHS
release with the fixes from the unofficial version, and make it available again on the
source website as the new **The Vault v9.0 "Back to Home" edition**?

Let's get to work!

## Content & Features

==================================================================================

The Vault introduces several short and long quests, increases tactical combat difficulty,
adds a selection of balanced items, and allows for item upgrades. The mod is divided
into the following components:

### 1. Component: The Vault Item Upgrades - Item Revisions Compatibility

==================================================================================

This component ensures compatibility between items introduced by The Vault and the *Item Revisions (IR)* mod.

Install this component only if you plan to install *Item Revisions* LATER in your mod order.
This module was originally created by Beleg33 for version 7.2a. It has not been revised or updated for this   
edition, as I am not familiar with the *IR* mod, so it remains exactly as it was.

==================================================================================

### 2. Component: Modified Holy Cloak (clck21.itm)

==================================================================================

This component tweaks the Holy Cloak from the Isle of Balduran quest, ensuring it is no longer treated only as a quest item.

==================================================================================

### 3. Component: Modified Shandalars Cloak (clck22.itm)

==================================================================================

This component tweaks the Shandalars Cloak from the Ulgoth's Beard quest, ensuring it is no longer treated only as a quest item.

## Installation and Compatibility

==================================================================================

The Vault can be installed on BGT, BGEE and EET. Before installing mod on BGEE/EET,
you must first install the current DLC Merger (EE) and then the current EEFixpack.

To install, unzip the file to your main game folder and double click on Setup-Vault.exe.
To uninstall, double-click on Setup-Vault.exe and select the Uninstall option.

The main quest of The Vault replaces the original sword "Vampire's Revenge" - SW1H19.itm
with SW1HVAM.itm, so The Vault will NOT be compatible with other mods that require SW1H19!
A confirmed exception is the NTotSC mod, which detects The Vault and allows Torqion's quest
to be completed with the SW1HVAM.itm sword.

In version 7.2a, Beleg33 introduced compatibility with Item Revisions, which should be
installed after The Vault (nothing has been changed regarding this).

The Vault should be installed equally early. I install it right after NTotSC.

Project Infinity is a dedicated tool for EET installation.

The Vault languages: Chinese, English, French, Italian, Polish, Russian, Spanish.
